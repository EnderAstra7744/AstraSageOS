# AstraSage OS 3.0 (Native Android · Kotlin)

Gerçek telefon uygulamaları + gerçek dosya sistemi + masaüstü arayüzü.

## Özellikler
- Kurulum: dil (TR/EN) + kullanıcı / şifre (CPU-RAM yok)
- Masaüstü: duvar kağıdı, gerçek uygulama ikonları
- Boş alanda sürükle → mavi seçim kutusu (çoklu seçim)
- Basılı tut → ikon sürükle (çoklu seçimde birlikte taşınır)
- Dosya Gezgini → gerçek depolama; **📌 Masaüstü** ile klasör/dosya sabitle
- AST Terminal → pwd, ls, cd, cat, mkdir, touch, rm, df, neofetch (gerçek FS)
- Başlat menüsü, görev çubuğu

## Çalıştırma
1. Android Studio ile `AstraSageOS` klasörünü aç
2. Sync + Run
3. Dosya gezgini için Android 11+: **Tüm dosyalara erişim** izni ver

## Not
HTML simülasyon kaldırıldı; sadece native uygulama.
